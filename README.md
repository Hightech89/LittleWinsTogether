# Little Wins Together

Little Wins Together is a calm, supportive online community for parents raising children with autism.

The goal of this project is to create a space where parents can:
- Share experiences
- Celebrate small victories ("little wins")
- Ask questions and support each other
- Discover helpful resources shared by other families

## Core Principles

This community should feel:
- Calm
- Safe
- Supportive
- Human and non-corporate

The design and language should avoid startup-style marketing and instead focus on quiet reassurance.

## MVP Features

Version 1 will include:

- Landing page
- Account creation (email verification required)
- Public browsing of discussions
- Private posting and commenting for logged-in users
- Categories:
  - General Support
  - Daily Little Wins
  - School & IEPs
  - Behavior & Meltdowns
  - Therapies & Services
  - Parent Burnout & Self-Care
- Location tags for region-specific discussions

## Tech Direction

Planned stack:

Frontend: Next.js  
Backend: Supabase  
Auth: Supabase email authentication  
Database: Postgres via Supabase
