# Cursor Instructions

You are helping build a web app called Little Wins Together.

## Project Purpose
Little Wins Together is a calm, supportive online community for parents raising children with autism.

The emotional goal of the site is to feel calm, safe, reassuring, and human.

## Product Model
- Public users can read discussions
- Posting and commenting require an account
- Accounts require verified email
- Users can choose a display name instead of using their real name
- Some discussions will use optional location tags

## MVP Priorities
Focus only on the version 1 MVP unless explicitly told otherwise.

Version 1 includes:
- Landing page
- Signup and login
- Public browsing of discussions
- Category pages
- Posts
- Comments
- Basic profiles with display names

## Design and Tone Rules
The interface should feel:
- calm
- spacious
- soft
- supportive

Use:
- generous whitespace
- rounded corners
- soft blue accents
- simple layouts
- gentle typography

Avoid:
- flashy startup design
- dark or aggressive styling
- overly bright colors
- crowded UI
- gamification
- productivity app patterns

## Copy Rules
Use calm, human language.

Prefer phrases like:
- supportive space
- little wins
- community
- support
- encouragement
- connection

Avoid phrases like:
- success stories
- unlock
- level up
- crush it
- growth hacks
- supercharge

## Engineering Rules
- Keep implementation simple
- Do not introduce unnecessary libraries
- Do not add features that were not requested
- Do not overengineer
- Keep folder structure clean and readable
- Explain proposed file changes clearly before making major changes
