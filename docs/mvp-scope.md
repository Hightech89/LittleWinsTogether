# MVP Scope

## Goal

Build a simple, calm, supportive forum-style community for parents raising children with autism.

The goal of version 1 is to launch a functional community space with minimal complexity.

Avoid building unnecessary features early.

## Version 1 Must Include

Core features:

- Landing page
- User signup and login
- Email verification
- Display name for users
- Category browsing
- Create posts
- Comment on posts
- View discussions without logging in

## Categories

The initial categories will be:

- General Support
- Daily Little Wins
- School & IEPs
- Behavior & Meltdowns
- Therapies & Services
- Parent Burnout & Self-Care

## Location Tags

Some discussions may be location specific.

Location tags allow parents to indicate region without creating complicated subforums.

Examples:

- Missouri
- Texas
- Ontario
- UK

Tags are optional.

## Not Included in Version 1

Do NOT build these yet:

- Direct messaging
- Notifications
- Mobile apps
- Groups
- Advanced profiles
- Gamification
- Leaderboards
- Ads
- Paid tiers
- AI features

## Possible Version 2 Features

These can be explored later:

- Anonymous posting
- Saved posts
- Community resource library
- Moderator dashboard
- Report system
- Email digest of community activity
